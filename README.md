# Operação Maré Baixa

Jogo de investigação criminal para 2 a 6 jogadores. O dossiê é impresso e o terminal SIGIC roda no navegador, no celular ou no computador.

## Conteúdo

- `index.html` — terminal SIGIC (consultas, mandados, laudos, quadro de provas e acusação final)
- `img/` — fotos dos suspeitos e da Casa 14
- `kit/Operacao_Mare_Baixa_Kit.pdf` — dossiê para imprimir em A4

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta, mantendo a pasta `img` ao lado do `index.html`.
2. No repositório, abra **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e clique em **Save**.
4. Em um ou dois minutos o site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Acesso

- Matrícula: `DFIC-0814`
- Senha: `MAREBAIXA`

## Progresso salvo

O jogo salva tudo automaticamente no navegador de cada aparelho: mandados, provas fixadas, anotações, laudos recebidos, relógio da partida, a tela aberta e a acusação. Dá para fechar o navegador ou desligar o celular e continuar depois.

O progresso só se perde se:
- alguém tocar em **Reiniciar o caso**;
- os dados do site forem apagados nas configurações do navegador;
- o jogo for aberto em aba anônima.

Para continuar em outro aparelho, use **Equipe → Progresso**: copie o código em um aparelho e cole no outro.

## Aviso

A solução do caso está dentro do `index.html`. Quem não quiser estragar a surpresa não deve abrir o código-fonte antes de jogar.

Todos os personagens, empresas e órgãos são fictícios.
